# Git Branching Notes

Today I practiced creating and using a Git branch. 

## What I learned

- A branch lets me work on changes separately from main.

- main should stay clean and stable. 
- git switch -c creates a new branch and switches to it. 
- git branch shows available branches. 
- git switch main returns to the main branch. 
- git merge  brings branch changes into the current branch. 

# Cloud Engineer Connection

Branches are useful when working on scripts, documentation, configuration files, infrastructure code, and cloud projects without directly changing the stable main branch.
