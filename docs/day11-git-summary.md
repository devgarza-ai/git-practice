## Important Concepts 

Git is the local version control tool that tracks file changes and saves project history. 

GitHub is the online platform where Git repositories can be stored, shared, and used as part of a portfolio. 

A commit saves staged changes locally 

A push sends local commits to GitHub. 

A README file explains what a project is and helps make a GitHub repository easier to understand.
