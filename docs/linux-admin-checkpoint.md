# Linux Admin Checkpoint

## Commands Reviewed
- sudo is short for superuser do. This command gives us administrator priveleges to run root commands. 
- git status shows us the current state of our repository 
- chown changes ownership of a file 

## Permission Notes
- chmod 755 gives owner read/write/execute and groups and other users read/execute
- chmod 700 gives owner read, write and execute permissions only 
- chmod 644m gives owner read/write and groups and others read only

## User Management Notes
- useradd is used for adding new users 
- userdel is used for deleting any user no longer being used
- usermod is used for changing which groups the user is associated with

## Git Connection
- git commit saves a checkpoint in the local repository 
- git push pushes our committs to the remote GitHub repository 
- git pull pulls any committs from the remote repository into our local repository
